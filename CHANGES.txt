v2.0.0
 - Add opt-in authentication for devices and clients, using
   Server(device_auth=True, client_auth=True). Both default to off
 - Add client sign in with an access identifier, alongside email sign in
 - Hold a failed registration open for auth_failure_delay seconds
 - Breaking: add_device takes the authkey as its third argument, and takes
   manufacturer_id and product_id as keyword arguments
 - Breaking: Server takes certfile and keyfile as Path objects
 - Breaking: Remove support for Python 3.10
 - Add RGBW dimmer channel
 - Replace the existing connection when a device or client registers again,
   instead of rejecting the new registration
 - Server.stop() takes a timeout, and closes the connections that outlast it
 - Devices time out registration, and shut down when a background task fails
 - Fix a client closing its own connection by asking for an unknown channel
 - Fix the success value reported when a device sets a channel value
 - Fix field types in the protocol definitions
